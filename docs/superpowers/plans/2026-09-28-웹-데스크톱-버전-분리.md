# 구현 계획: 웹 버전과 데스크톱 버전 분리

설계 문서: `docs/superpowers/specs/2026-09-28-웹-데스크톱-버전-분리.md`

태스크 7개로 나눈다. 태스크마다 검증 방법을 붙인다.

## 태스크 1. 폴더 분리

파이썬 파일과 자료를 `desktop_version/`으로 모으고 `web_version/`을 만든다.
파이썬 코드는 고치지 않는다.

**검증** — `cd desktop_version && python3 app.py`로 그림판이 뜨고 인식이 된다.

## 태스크 2. 가중치 내보내기

`가중치내보내기.py`가 `mnist_cnn.pt`를 읽어 `가중치.bin`과 `가중치정보.json`을 만든다.

**검증** — 파라미터 421,642개, 파일 크기 1,686,568바이트.
설계 문서에는 텐서가 6개라고 적혀 있었으나 실제로는 weight와 bias가 각각 4개씩
모두 8개다. 설계 문서를 고쳤다.

## 태스크 3. 검증 데이터 만들기

`검증데이터만들기.py`가 확대 무리 200장과 획 무리 25장을 만든다.

**검증** — 파이썬 정확도가 두 무리 모두 나오고, 확대 무리가 97% 이상이다.
MNIST 시험 자료는 태스크 1에서 이미 내려받아 두었으므로 오프라인에서도 열린다.

## 태스크 4. 자바스크립트 순전파

`모델.js`와 `검증.html`의 순전파 검사.

**검증** — 같은 28x28 입력에 대한 확률의 최대 절대차가 1e-4 이하.

## 태스크 5. 자바스크립트 전처리와 전체 정확도

`전처리.js`와 `검증.html`의 정확도 검사.

**검증** — 확대 무리 200장에서 97% 이상.

## 태스크 6. 웹 앱 화면

`index.html`, `스타일.css`, `그림판.js`, `앱.js`.

**검증** — 브라우저에서 숫자를 그리면 상위 3개 후보가 나온다.

## 태스크 7. 문서 3개

루트, `desktop_version/`, `web_version/`의 `CLAUDE.md`.

**검증** — 앞선 태스크 6개의 결과(실측값 포함)가 문서에 반영되어 있다.

## 고친 점과 남은 점

구현 중에 찾아 고친 것.

1. `면적평균축소`가 원본 경계를 넘어 읽을 수 있었다. `19 * (21 / 19)`가
   `21.000000000000004`가 되어 배열 밖을 읽는다. `Math.min`으로 잘라 고쳤다.
2. `모델불러오기`가 `가중치.bin` 길이를 검사하지 않아 네이티브 `RangeError`가
   그대로 올라왔다. `byteLength % 4`를 먼저 검사하게 했다.
3. `소프트맥스`가 `Math.max(...점수)`로 배열을 펼쳤다. 원소가 10개라 지금은
   안전하지만 큰 텐서에 다시 쓰면 인수 개수 한계에 걸린다. 반복문으로 바꿨다.
4. `검증.html`이 정규화 식을 따로 적고 있었다. `전처리.js`의 `정규화`를 쓰게 했다.
5. `검증.html`에서 전처리가 `null`이면 곧바로 되돌아가 요약 줄이 나오지 않았다.
   기록만 하고 계속 가도록 고쳤다.
6. 적재 중에 그린 그림이 적재가 끝난 뒤 자동으로 인식되지 않았다. 고쳤다.
7. `file://`로 열면 모듈이 CORS로 막혀 화면이 조용히 멈췄다. 안내 문단을 미리 넣고
   모듈이 실행되면 지우는 방식으로 바꿨다. `onerror` 이벤트가 `file://`에서 실제로
   발화하는지 확인하지 못해 그 방식은 쓰지 않았다.
8. 검증 표본이 확대 무리 200장뿐이었다. 전부 28x28을 정확히 10배 확대한 것이라
   바운딩 박스 변이 언제나 10의 배수여서, 사람이 마우스로 그렸을 때만 생기는
   상황을 한 번도 시험하지 못했다. `app.py`의 그리기 함수로 획을 그린 획 무리
   25장을 더했다.

남은 것.

- 데스크톱 앱(`app.py`)은 `tkinter`가 없는 환경에서 실행해 보지 못했다. 코드가
  임포트되는 것까지만 확인했다. macOS에서 직접 실행해 확인해야 한다.
- 28x28 중간 결과는 파이썬과 최대 1.0(0~1 기준)까지 벌어진다. 무게중심 이동의
  정수 픽셀 이동이 한 칸 갈리면 가장자리에서 크게 차이가 난다. 최종 정확도가
  기준을 넘으므로 그대로 둔다.
